# 과제-11: 삽입 정렬과 쉘 정렬의 성능 비교

## 실험 환경
- 데이터: 0~1,000,000 사이의 무작위 정수. n = 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000
- 정렬: 삽입 정렬, 쉘 정렬(기본 간격 n/2, n/4, ..., 1), 쉘 정렬(Knuth 간격 1, 4, 13, 40, ...)
- 각 데이터 크기마다 같은 원본의 복사본을 세 정렬에 입력했다. Seed: 20261031
- 비교 횟수: 데이터 값끼리 비교할 때마다 1회. 반복문 조건 검사, 데이터 생성, 배열 복사는 세지 않았다.
- Knuth 간격은 n보다 작은 가장 큰 값부터 시작해서 역순으로 적용했다. (n=1,000이면 364, 121, 40, 13, 4, 1)
- 모든 정렬 결과가 오름차순인지 확인했고, 전부 올바르게 정렬되었다.

## 측정 결과 (비교 횟수)

| n | 삽입 정렬 | 쉘 정렬 (기본) | 쉘 정렬 (Knuth) |
|---|---|---|---|
| 1,000 | 252,713 | 15,449 | 13,593 |
| 2,000 | 983,435 | 35,730 | 32,101 |
| 4,000 | 4,036,699 | 87,217 | 74,062 |
| 8,000 | 16,234,789 | 203,415 | 179,464 |
| 16,000 | 63,950,722 | 489,290 | 410,942 |
| 20,000 | 100,033,389 | 606,718 | 556,141 |

n이 2배가 될 때 비교 횟수가 몇 배가 되었는지 (1,000 → 2,000 → 4,000 → 8,000 → 16,000)

| 정렬 | 증가 배율 |
|---|---|
| 삽입 정렬 | 3.89 / 4.10 / 4.02 / 3.94 배 |
| 쉘 정렬 (기본) | 2.31 / 2.44 / 2.33 / 2.41 배 |
| 쉘 정렬 (Knuth) | 2.36 / 2.31 / 2.42 / 2.29 배 |

## 분석

### 데이터 크기에 따른 변화
- 삽입 정렬은 n이 2배가 되면 비교가 약 4배가 되었다. 실측값은 n²/4와 거의 같다. (예: n=20,000에서 100,033,389 ≈ 20,000²/4 = 100,000,000) 비교가 n²에 비례한다.
- 쉘 정렬은 n이 2배가 될 때 약 2.3~2.4배만 늘었다. n이 1,000에서 16,000으로 16배 커질 때 삽입 정렬은 약 253배, 쉘 정렬은 약 32배(기본)와 약 30배(Knuth) 늘었다. 쉘 정렬의 비교는 대략 n의 1.2~1.3제곱에 비례한다.

### 삽입 정렬과 쉘 정렬의 차이
- n=1,000에서 삽입 정렬은 쉘 정렬(기본)의 약 16배였지만, n=20,000에서는 약 165배(Knuth는 약 180배)로 격차가 계속 커졌다. n이 클수록 쉘 정렬이 훨씬 유리하다.
- 이유: 삽입 정렬은 값을 **한 칸씩만** 옮겨서, 멀리 떨어진 값이 제자리를 찾으려면 그만큼 많이 비교해야 한다. 쉘 정렬은 큰 간격으로 먼저 정렬해서 값을 **멀리 한 번에** 보낸다. 간격이 줄어드는 동안 데이터가 점점 정렬에 가까워지고, 마지막 간격 1(삽입 정렬)에서는 거의 정렬된 데이터를 다루므로 비교가 크게 줄어든다.

### 기본 간격과 Knuth 수열의 차이
- 모든 크기에서 Knuth 수열의 비교 횟수가 더 적었다. 차이는 약 9~19%(기본÷Knuth = 1.09~1.19배)였다.
- n=20,000에서 쉘 정렬(기본)은 간격이 14단계(10000, 5000, ..., 1)이고 Knuth는 9단계(9841, 3280, ..., 1)였다. 한 단계마다 대략 n번에 가까운 비교가 필요하므로, 단계가 적은 Knuth가 비교 횟수에서 유리했다.

### 간격 수열이 성능에 영향을 주는 이유
- 쉘 정렬은 마지막에 간격 1로 삽입 정렬을 하므로 항상 정렬은 되지만, 그 전 단계에서 **얼마나 정렬 상태에 가깝게 만들어 놓는지**가 성능을 정한다.
- 기본 간격(n/2, n/4, ...)은 서로 배수 관계인 값이 많다. 예를 들어 n=2,000이면 1000, 500, 250이 모두 250의 배수여서, 이 단계들에서는 같은 그룹의 값끼리만 비교하고 다른 그룹의 값과는 작은 간격에서야 섞인다. 반면 Knuth 수열은 이웃한 두 간격이 항상 서로소(1과 4, 4와 13, 13과 40, ...)라서 단계마다 다른 값들과 섞이고, 같은 비교를 반복하는 일이 적다.
- 이번 실험에서는 두 수열의 차이(약 9~19%)가 삽입 정렬과의 차이(수십~수백 배)보다 훨씬 작았다. 즉 간격 수열보다 **큰 간격부터 줄여 가는 쉘 정렬의 구조 자체**가 성능을 크게 좌우했다.

## 한계
- 데이터 크기마다 무작위 데이터 한 세트만 측정해서, 데이터가 달라지면 숫자가 조금 달라질 수 있다. (기본÷Knuth 배율이 크기마다 1.09~1.19로 일정하지 않은 것도 그 영향일 수 있다.)
- 비교 횟수만 측정했고 데이터 이동 횟수와 실행 시간은 측정하지 않았다.
- Knuth 수열의 시작 간격은 과제 설명대로 "n보다 작은 가장 큰 간격"으로 했다. 시작 간격을 다르게 정하면(예: n/3 이하) 결과가 달라질 수 있다.
