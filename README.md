# 과제-05: 순차 탐색과 이진 탐색 트리 탐색의 비교

# 측정 결과

| 항목 | 값 |
|---|---|
| 순차 탐색 총 비교 횟수 | 4820 |
| 순차 탐색 평균 비교 횟수 | 96.40 |
| BST 탐색 총 비교 횟수 | 356 |
| BST 탐색 평균 비교 횟수 | 7.12 |
| BST 생성 시 총 비교 횟수 | 595 |

# 성능 차이 분석

순차 탐색은 평균 96.40회, BST 탐색은 평균 7.12회로, BST가 약 13배 더 적은 비교로 탐색에 성공했다.
이는 BST가 매 비교마다 탐색 범위를 절반씩 줄여나가는 반면, 순차 탐색은 값을 찾을 때까지
배열을 처음부터 순서대로 훑어야 하기 때문이다.

# BST 생성 비용을 고려한 분석

BST를 생성하는 데 595회의 비교가 추가로 발생했다. 이를 50회 탐색 비용(356회)에 더하면
총 951회로, 순차 탐색만의 총 비용(4820회)보다 여전히 훨씬 적다. 즉 데이터를 한 번만 저장하고
여러 번 탐색할수록 BST 생성 비용은 금방 상쇄되고, 전체적으로 BST 방식이 유리하다.

# 트리 구조에 따른 성능 변화

이번 실험은 데이터를 랜덤한 순서로 삽입했기 때문에 비교적 균형 잡힌 트리가 만들어져
좋은 효율을 보였다. 그러나 만약 데이터가 이미 정렬된 순서로 삽입되었다면
BST는 한쪽으로만 뻗어나가는 편향 트리(연결 리스트와 동일한 구조)가 되어, 탐색 성능이
순차 탐색과 같은 수준으로 저하되었을 것이다. 따라서 BST의 성능은 삽입 순서(트리의 균형도)에
크게 좌우된다.



# 과제-06: 순차 탐색, BST, AVL 트리의 성능 비교

# 삽입 결과

| 항목 | 값 |
|---|---|
| 실제로 저장된 서로 다른 값의 수 | 90 |
| 중복으로 삽입되지 않은 값의 수 | 10 |
| 배열 생성 비교 횟수 | 4296 |
| BST 생성 비교 횟수 | 705 |
| AVL 생성 비교 횟수 | 530 |
| 배열 길이 | 90 |
| BST 높이 | 14 |
| AVL 높이 | 8 |

# 탐색 결과

| 항목 | 총 비교 횟수 | 평균 비교 횟수 |
|---|---|---|
| 순차 탐색 | 4118 | 82.36 |
| BST 탐색 | 439 | 8.78 |
| AVL 탐색 | 310 | 6.20 |

# BST와 AVL 트리의 높이가 다른 이유

BST는 데이터가 삽입되는 순서를 그대로 반영해 트리를 구성하므로, 삽입 순서에 따라 한쪽으로
치우친 모양이 될 수 있다. 반면 AVL 트리는 삽입할 때마다 좌우 서브트리의 높이 차이(균형 인자)를
확인하여 2 이상 벌어지면 즉시 회전(LL/RR/LR/RL)을 수행해 균형을 복구한다. 그 결과 AVL 트리는
항상 O(log n)에 가까운 높이를 유지하지만, BST는 입력 순서에 따라 훨씬 더 높아질 수 있다.
실제 실행 결과에서도 BST 높이는 14, AVL 높이는 8로, 같은 90개의 데이터를 저장했음에도
AVL이 거의 절반에 가까운 높이로 유지된 것을 확인할 수 있다.

# 트리 높이가 탐색 비교 횟수에 미치는 영향

탐색 시 한 번의 비교마다 한 단계씩 아래로 내려가므로, 최악의 경우 비교 횟수는 트리 높이에
비례한다. 따라서 높이가 낮은 AVL 트리는 BST보다 평균 비교 횟수가 더 적게 나왔다
(AVL 평균 6.20회 vs BST 평균 8.78회). 높이가 그대로 탐색 비용과 직결된다는 것을 실험
결과로 확인할 수 있다.

# 생성 비용과 탐색 비용 비교

AVL 트리는 삽입 시 회전으로 균형을 유지하는 추가 작업이 있지만, 이번 과제 기준의 비교 횟수에는
회전 판단 자체(높이·균형 인자 계산)는 포함되지 않는다. 그 결과 AVL 생성 비교 횟수(530)가
오히려 BST 생성 비교 횟수(705)보다 더 적게 나타났다. 이는 AVL 트리가 삽입 과정에서 균형을
유지하여 트리의 높이를 낮게 유지함으로써, 삽입 위치를 찾기 위한 비교 횟수 자체도 줄어들었기
때문으로 해석할 수 있다.

생성 비용뿐 아니라 탐색 비용까지 고려하면 AVL 트리의 우위는 더욱 분명해진다. AVL 생성
비교(530) + AVL 탐색 비교(310) = 840회인 반면, BST 생성 비교(705) + BST 탐색 비교(439) =
1144회로, AVL 트리가 생성과 탐색을 모두 포함한 전체 비용에서도 BST보다 적은 비교 횟수를
기록했다. 즉 AVL 트리는 회전이라는 추가 로직을 감수하면서도, 이번 실험에서는 생성과 탐색
양쪽 모두에서 BST보다 효율적이었다.
